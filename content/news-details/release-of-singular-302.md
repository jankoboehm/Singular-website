<p><strong>Singular</strong> version 3.0.2  available for Windows / Mac OS / Linux:</p>
<h3>Updates for version 3.0.2</h3>
<!--docid::SEC1332::-->
<p>The current version 3.0.2 is mainly a bug fix release, but it contains also some new features:</p>
<ul>
<li> factory, libfac updated for gcc 4.1.x </li>
<li> configure/speed improved for 64bit architectures </li>
<li> new library: dmod.lib ( <a href="/old/Manual/3-0-2/sing_437.htm">dmod_lib</a>) </li>
<li> new library: perron.lib ( <a href="/old/Manual/3-0-2/sing_499.htm">perron_lib</a>) </li>
<li> improved center.lib ( <a href="/old/Manual/3-0-2/sing_416.htm">center_lib</a>): revised implementation, new functions (sa_reduce etc.) </li>
<li> revised ncalg.lib ( <a href="/old/Manual/3-0-2/sing_454.htm">ncalg_lib</a>): new algebras, U(sl_n) and U(g_2) changed to conform GAP. </li>
<li> new algorithms in primdec.lib ( <a href="/old/Manual/3-0-2/sing_815.htm">primdec_lib</a>): radical et al. </li>
<li> improved version of  <a href="/old/Manual/3-0-2/sing_284.htm">slimgb</a>, incorporated into  <a href="/old/Manual/3-0-2/sing_208.htm">groebner</a> </li>
<li> improved module generator (<code>modgen</code>) </li>
<li> experimental: new type  <a href="/old/Manual/3-0-2/sing_68.htm">bigint</a> </li>
<li> more architectures: Solaris on x86/opteron, ... </li>
<li> build process improved: builds automatically without patches on 64bit architectures </li>
</ul>
