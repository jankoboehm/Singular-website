<p><strong>Singular</strong> version 3.0.1  available for Windows / Mac OS:</p>
<h3>Updates for version 3.0.1</h3>
<!--docid::SEC1209::-->
<p>The current version 3.0.1 is mainly a bug fix release, but it contains also some new features:</p>
<ul>
<li> NTL upgraded to version 5.4 </li>
<li> new library: absfact.lib  <a href="/old/Manual/3-0-1/sing_681.htm">absfact_lib</a> </li>
<li> new procedures in primdec.lib:  <a href="/old/Manual/3-0-1/sing_783.htm">absPrimdecGTZ</a> </li>
<li> new procedures in standard.lib:  <a href="/old/Manual/3-0-1/sing_302.htm">weightKB</a> </li>
<li> build process improved: new make target <code>install_all</code> </li>
<li> improved version of  <a href="/old/Manual/3-0-1/sing_280.htm">slimgb</a>, incorporated into  <a href="/old/Manual/3-0-1/sing_203.htm">groebner</a> </li>
<li> arithmetic in Z/pZ for architecture x84_64 improved (by 25 %) </li>
</ul>
