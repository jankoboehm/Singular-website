<p>available for most Unix platforms:</p>
<h3>News for version 3.0.4</h3>
<!--docid::SEC1459::-->
<p> </p>
<ul>
<li> licence changed: due to the need to use stuff under (L)GPL3, all parts of S<small>INGULAR</small> are licenced under GPL (resp. LGPL) version 2, or (at your option) version 3 </li>
<li> new command: ( <a href="/old/Manual/3-0-4/sing_302.htm">univariate</a>): test polynomials for being univariate. </li>
<li> new command: ( <a href="/old/Manual/3-0-4/sing_306.htm">variables</a>): list of all variables occuring in a polynomial, ideal or matrix. </li>
<li> syntax change:  <a href="/old/Manual/3-0-4/sing_404.htm">ncalgebra</a> should be substituted by  <a href="/old/Manual/3-0-4/sing_403.htm">nc_algebra</a>. <code>ncalgebra</code> is now depreciated, but still supported </li>
<li> library  <a href="/old/Manual/3-0-4/sing_511.htm">nctools_lib</a> updated to use <code>nc_algebra</code>,<br /> <a href="/old/Manual/3-0-4/sing_515.htm">Weyl</a>,  <a href="/old/Manual/3-0-4/sing_518.htm">Exterior</a>,  <a href="/old/Manual/3-0-4/sing_519.htm">findimAlgebra</a> do not change the current ring but return the new structure </li>
<li> kernel: use Conway polynomials and support more finite fields </li>
</ul>
