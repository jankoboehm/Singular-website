<h2>News for version 4.2.1</h2>
<p>New commands:</p>
<ul>
<li>Letterplace: dim, rightStd for qrings ( <a href="/old/Manual/4-2-1/sing_799.htm#SEC853">LETTERPLACE</a>) </li>
<li>Letterplace: map, fetch, imap ( <a href="/old/Manual/4-2-1/sing_128.htm#SEC168">map</a>,  <a href="/old/Manual/4-2-1/sing_246.htm#SEC286">fetch</a>,  <a href="/old/Manual/4-2-1/sing_267.htm#SEC307">imap</a>) </li>
</ul>
<p>New libraries:</p>
<p> </p>
<ul>
<li>decomp.lib: functional decomposition of polynomials ( <a href="/old/Manual/4-2-1/sing_1273.htm#SEC1354">decomp_lib</a>) </li>
<li>hodge.lib: algorithms for Hodge ideals ( <a href="/old/Manual/4-2-1/sing_2854.htm#SEC2935">hodge_lib</a>) </li>
<li>tateProdCplxNegGrad.lib: sheaf cohomology on product of projective spaces ( <a href="/old/Manual/4-2-1/sing_2964.htm#SEC3045">tateProdCplxNegGrad_lib</a>) </li>
</ul>
<p>Changes in the kernel/build system:</p>
<ul>
<li><code>liftstd</code> (with 2 arguments) improved ( <a href="/old/Manual/4-2-1/sing_289.htm#SEC329">liftstd</a>) </li>
<li>building on Cygwin with shared libaries </li>
<li>building the manual via <code>--enable-doc-build</code> </li>
</ul>
