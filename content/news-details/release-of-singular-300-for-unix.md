<p>Release of <strong>Singular</strong> version 3.0.0 is now  available for most Unix platforms (including Mac PPC  Darwin):</p>
<h3>NEWS in SINGULAR 3.0.0</h3>
<!--docid::SEC1204::-->
<p>The current version 3.0.0 is the first in the new release series version 3-0.</p>
<p><strong>Singular</strong> version 3 has a greater functionality and an improved architecture. Major new features are:</p>
<ul>
<li> <a href="/old/Manual/3-0-0/sing_467.htm">Dynamic modules</a> </li>
<li> non-commutative extension  <a href="/old/Manual/3-0-0/sing_343.htm">PLURAL</a> </li>
<li> name spaces ( <a href="/old/Manual/3-0-0/sing_128.htm">package</a>) </li>
<li> easy manipulation of rings ( <a href="/old/Manual/3-0-0/sing_274.htm">ringlist</a>) </li>
<li> improved speed of maps ( <a href="/old/Manual/3-0-0/sing_288.htm">subst</a>,  <a href="/old/Manual/3-0-0/sing_107.htm">map</a>) </li>
<li> variant of Faugeres F4:  <a href="/old/Manual/3-0-0/sing_280.htm">slimgb</a>. </li>
<li> improved factorization (integration of NTL, factorization over algebraic extensions, zeroset.lib) </li>
<li> improved gcd of polynomials (including bug fixes) </li>
<li> ports to more architectures including automatic building from source (fink on Mac, ebuild on Gentoo) </li>
<li> more help browsers supported, user extendable (help.cnf) </li>
<li> better support of graded modules </li>
<li> many bugs fixed </li>
</ul>
<p>Besides theses internal changes, <strong>Singular</strong> version 3 offers many new features and functionalities (which were partly already incorporated in the 2-1 pre-release series).</p>
