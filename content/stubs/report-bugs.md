<p>To report bugs, or to propose new features, open a GitHub issue.</p>
<div class="legacy-actions">
<a class="button" href="https://www.github.com/Singular/Singular/issues">Open Singular GitHub issues</a>
</div>

<p>Alternatively, use <a href="mailto:singular@rptu.de">email</a>. For bugs, please include the following information:</p>
<ol>
<li>Provide a short title characterizing the bug.</li>
<li>Add the Singular code highlighting the bug.</li>
<li>Indicate the Singular version in which the bug occurs.</li>
<li>If known to you, provide the specific component of Singular in which the bug occurs.</li>
</ol>
<p>You may also use GitHub issues or email to propose new Singular features.</p>
<p>For help and support, use the manual.</p>
<div class="legacy-actions">
<a class="button button--secondary" href="singular-manual.html">Open the Singular manual</a>
</div>
